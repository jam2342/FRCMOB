# Navigation updates — 2026-10-18

## Navigation

| Trigger | Previous behavior | New behavior |
|---|---|---|
| Home event heading | Plain text; separate View Event button | Name links directly to that event's schedule |
| Rankings for another Home event | A global button used the selected event, even when a different live event appeared first | Standalone Home button and event-card Rankings pill removed; rankings remain on event pages |
| Today's Events rail | Clicking an event silently changed the rankings/stream context | Name links to its schedule; Rankings links directly to that event’s standings |
| Home countdown | Read-only value beside an Open Next Live button | Countdown links to its exact match |
| Events schedule on a phone | First tap expanded, second tap opened Match Center | One tap opens Match Center |
| Events schedule on desktop | Plain match name plus Match Details button | Match name links to Match Center |
| Favorites | Plain event/team names plus Events/Team Details buttons; next match was plain text | Names and next match are links; each event has a Rankings link |
| Deep Compare | Plain team name plus Team Details button | Team name links to Team Center, retaining the event context |
| Mobile Match Center event name | Plain label | Links to the event's schedule |

Links retain normal keyboard, browser Back and open-in-new-tab behavior. The mobile Info control says Event info.
